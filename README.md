# Woba S Launcher (simulador + launcher estilo Windows Phone 8 en Android)

Launcher en **Java puro** (Views + Canvas propios), sin Kotlin, sin Compose y sin
dependencias de AndroidX. Compila con `gradle assembleDebug`.

Fuentes: `app/src/main/assets/fonts/wp_light|regular|semibold|bold.ttf` (Selawik).
